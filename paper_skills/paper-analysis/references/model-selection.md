# Model Selection Principles

Use this reference for stable, non-time-sensitive guidance. Do not copy fixed leaderboard claims into answers unless they have been freshly verified.

## Routing Heuristics

- Idea discussion, paper brainstorming, and general writing:
  - Prefer strong long-context reasoning and fluent drafting models.
- Fast iteration on polishing or translation:
  - Prefer lower-latency models when the task is repetitive and the prompt is already well-structured.
- Coding, experiment scripts, and repo edits:
  - Prefer coding-specialized models with stronger tool use and codebase navigation.
- Final paper polish:
  - Prefer models that are strong at controlled rewriting and instruction adherence over models that merely sound creative.

## Answer Style

- Recommend by scenario, not by hype.
- Separate writing, coding, and review use cases.
- If the user asks for "latest/best/current", verify with current official or primary sources before answering.
