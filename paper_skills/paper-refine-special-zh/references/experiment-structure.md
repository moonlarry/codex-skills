# Experiment Structure

Apply this reference whenever the text is about 实验结果、消融实验、参数敏感性、效率分析或案例分析。

## Mandatory Paragraph Pattern

Every experiment paragraph must follow:

1. 结论句
2. 图表证据
3. 内容解释

This is mandatory.

## Paragraph-Level Rules

- 先用一句话交代该段的核心发现
- 再引用图号、表号、具体数值或对比对象支撑结论
- 最后解释原因、意义、机制、权衡或边界

## Multi-Paragraph Experiment Subsection

For a subsection with two or more experiment paragraphs, impose progression across paragraphs:

- 第 1 段：总述核心发现
- 第 2 段：展开关键模块贡献或消融证据
- 第 3 段：解释趋势、鲁棒性、权衡或边界情况

If the original text piles up numbers before making the point, reorder it.

If the evidence is weaker than the stated conclusion, soften the conclusion during the reviewer-style pass.
