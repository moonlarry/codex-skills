# Global Logic Check

Use this reference for subsection-, section-, and document-level polishing, and apply a smaller version of the same check for single paragraphs.

## What To Check

- 小节内段落顺序是否合理
- 相邻段落是否功能重复
- 是否存在“只报数据、不先给结论”的情况
- 章节之间是否存在主线断裂
- 引言或前文提出的主张是否在后文得到真正验证
- 同一术语是否在不同位置发生漂移
- 小节标题与正文是否匹配

## Common Failure Modes

- 段落先给细节，后给主旨
- 两段在做同一种工作，造成冗余
- 过渡句缺失，读者需要自己补逻辑
- 章节末尾没有解释结果意义
- 前文宣称创新点，后文实验并未有效支撑

## Rewrite Strategy

- 合并功能重复的段落
- 拆分同时承担太多功能的过载段落
- 必要时重排段落顺序
- 证据弱时主动收缩结论强度

## Whole-Document Rule

对整章或整篇输入，优先保证全局论证顺序、节间承接和术语一致性，再考虑局部句子是否优雅。
