# Output Format

## Standard Output

Return:

```text
Part 1 [Style-Calibrated Text]
<revised text for calibrated sections>

- Source kind: [own | reference | description | pre-existing guide]

- Target file: [filename]
- Sections calibrated: [list]
- Style elements applied:
  - Voice: [changes made]
  - Sentence rhythm: [changes made]
  - Transitions: [changes made]
  - Hedging: [changes made]
  - Formatting: [changes made]

Part 3 [Guardrail Verification]
- Factual content preserved: [yes/no - details if no]
- Citations unchanged: [yes/no - details if no]
- Numbers unchanged: [yes/no - details if no]
- Equations unchanged: [yes/no - details if no]
- No source terminology introduced: [yes/no - details if no]
- Hedging matches evidence: [yes/no - details if no]
- Plagiarism check: [passed/flagged - details if flagged]

Part 4 [Style Profile Summary]
- Voice profile: [summary statistics]

- Transition profile: [summary statistics]

- STYLE_GUIDE.md: [path or "not generated"]
- STYLE_METRICS.json: [path or "not generated"]

```

## Medium-Specific Output

### For LaTeX targets

Return valid LaTeX with:
- All commands preserved
- All environments intact
- Math notation unchanged
- Citation keys unchanged

### For Markdown targets

Return clean Markdown with:
- Headers preserved
- Links preserved
- Code blocks unchanged

### For Word targets (if applicable)

Return clean prose suitable for Word insertion.

## Output Directory

All generated files are placed in `psmfiles/` relative to the target manuscript directory.

If the target is `project/paper/main.tex`, outputs go to:
- `project/psmfiles/STYLE_GUIDE.md`
- `project/psmfiles/STYLE_METRICS.json`
- `project/psmfiles/RHETORICAL_PATTERNS.md`
- `project/psmfiles/CALIBRATION_REPORT.md`
